Open it like an app

On a computer, save this HTML file somewhere you can find it and double-click it. Everything works offline. Bookmark the opened page for quick access.

If your browser offers Add to Home Screen or Create shortcut, use it to keep this page close. Support for local files varies by mobile browser. This file does not register a service worker or promise an install prompt. A home-screen copy needs a browser that retains the page and its local storage.

Plans stay in this browser, for this file location. A new browser, moving the file, or clearing browser data may create an empty space. Export a backup before any of those changes. If saving is blocked, the app tells you and export still works.
